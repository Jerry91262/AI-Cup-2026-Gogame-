# 圍棋棋力預測系統 (Rank Prediction Pipeline)

本專案透過深度學習與戰術特徵工程，針對棋譜進行棋力預測。系統涵蓋從原始資料讀取、高維度特徵提取、資料分片到卷積神經網路訓練與驗證的完整流程。

---

## 🛠️ 系統管線架構 (Pipeline Stages)

| 階段 | 名稱 | 功能描述 |
| :--- | :--- | :--- |
| **Stage 1** | **CSV 讀取** | 載入原始棋譜與對局資料集 |
| **Stage 2** | **特徵提取** | 解析棋盤狀態並轉換為多維度張量特徵 |
| **Stage 3** | **WebDataset 分片** | 將特徵資料打包分片（Sharding），提升 I/O 讀取與訓練吞吐量 |
| **Stage 4** | **模型訓練** | 執行 ResNet 系列深度神經網路訓練 |
| **Stage 5** | **驗證與分數計算** | 評估測試集表現並計算最終預測準確率 |

## 🚀 模型迭代日誌 (Iteration Log)

### 📅 10/07 — Baseline 基準模型測試
* **實驗結果**：完成五階段管線建置與 Baseline 訓練，得出基準準確率 **26.10%**。
* **問題分析**：【資料不足，無法確認】*(請在此補充 10/07 觀察到的模型問題，例如：過擬合、收斂緩慢或局部特徵捕捉不足)*

### 📅 10/12 — 訓練策略與注意力機制引入
本階段新增四項優化方法，將驗證準確率提升至 **28.60%**：
1. **學習率排程優化（Learning Rate Decay）**：採用學習率衰退機制，初始設定最高學習率，隨訓練推進漸進平滑遞減。
2. **延長訓練週期（Epochs 擴充）**：將訓練週期增加至 **20 Epochs**，持續訓練直到準確率曲線趨於平緩收斂。
3. **幾何資料增強（Data Augmentation）**：利用棋盤對稱性，新增 **0°、90°、180°、270° 旋轉**以及**水平翻轉**。
4. **引入通道注意力機制（SE-ResNet）**：將主幹網路升級為 **SE-ResNet（Squeeze-and-Excitation ResNet）**，強化當前主要對戰區域的特徵權重。

### 📅 10/19 — 領域戰術特徵擴增與架構瓶頸修正
本階段針對圍棋領域知識（Domain Knowledge）與卷積架構進行深度改良：
1. **高維度戰術特徵工程（擴增至 751 維）**：
   * 引入**廣度優先搜尋（BFS）**演算法，精確計算棋塊氣數分級（**1 至 4 口氣**）、**基本眼位／禁手點**，並加入 **AlphaGo 邊界常數平面**。
   * 採用 **10 步抽樣間隔**提取 **25 個戰術截面**，將模型總輸入通道擴增至 **751 維**。
2. **神經網路架構改良**：
   * 修正卷積神經網路（CNN）瓶頸結構。
   * 導入**雙分支入口（Dual-Branch Stem）**搭配**全局空間金字塔池化（Global Spatial Pyramid Pooling）**，兼顧局部戰術細節與全盤大局視野。
   * 修正**「敵我視角盲區（color 欄位遺漏）」**：將固定黑白通道改為「第一人稱視角（我方 vs. 對手）」，解決模型不知道該預測黑方還白方棋力的嚴重漏洞。
   * 修正**「時序通道錯位與開局資訊遺失」**：將「前端補零 + 末端截取」改為**「過濾空盤根節點 + 從第 1 手錨定 + 末端補零」**，100% 保留開局佈局與定石並對齊全資料集時序。
   * 導入「落子順序編號平面（Move Number Encoding Planes）」：淘汰高達 99.7% 重複的 500 個全盤累積快照通道，改以全局與每 10 步區間的落子手數編碼搭配截面快照。總通道數由 751 降至 **353**（大幅減少 53% 記憶體與 I/O 負擔），同時讓 2D 捲積能直接捕捉行棋先後手順。
   * 強化「訓練監控與多維度分類指標」：在 history.csv 改記錄 train_loss 與 val_loss，並於訓練結束自動產出 10×10 混淆矩陣、Precision、Recall 與 F1-score。
